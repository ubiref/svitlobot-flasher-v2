# SvitloBot Flasher v2

Вебфлешер для встановлення прошивки SvitloBot на ESP32-C3 за допомогою [ESP Web Tools](https://esphome.github.io/esp-web-tools/).

## Використання

1. Відкрийте сайт у Chrome або Edge на комп’ютері через HTTPS.
2. Під’єднайте ESP32-C3 кабелем USB з підтримкою передачі даних.
3. Натисніть кнопку встановлення, виберіть порт і підтвердьте прошивку.

Прошивка розміщується у `firmware/svitlobot-esp32c3-full.bin`.
